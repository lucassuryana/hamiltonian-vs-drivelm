PLANNING PRINCIPLES
============================================================

1. Planning is performed over candidate ego actions.

2. Conflict is candidate-specific.

A predicted object is not automatically a conflict.

For each candidate pair, determine whether that candidate's expected motion would interact unsafely with the predicted behaviour of each relevant object.

3. Unsafe candidates are eliminated before evaluating future value.

4. Prediction uncertainty must not be added to the immediate cost L.

5. Immediate cost L measures only deviation from the historical ego behaviour.

6. Future value lambda describes how a viable candidate affects the ego vehicle's future ability to continue safely toward its goal.

Q10 — REACHABILITY AND IMMEDIATE COST L
============================================================

Q10. What are the physically reachable candidate speed-direction pairs?

First:

2. Copy them exactly as the baseline.
3. Use the reachability tables above to generate all physically reachable speed-direction pairs.

For every reachable pair, assign its immediate cost L based ONLY on distance from the baseline:

- low cost
  = same speed AND same direction as the baseline

- medium cost
  = one level away in speed OR one level away in direction

- high cost
  = one level away in BOTH speed and direction

Only one candidate can have low cost.

Do not use scene risk, object uncertainty, or predicted conflicts when assigning L.

============================================================
Q11 — CANDIDATE-SPECIFIC CONFLICT AND FUTURE VALUE LAMBDA
============================================================

Q11. How does each physically reachable candidate interact with the predicted environment?

For every candidate from Q10:

Step A — Candidate-specific interaction

Compare the candidate against every object marked "yes" in Q9.

Use the predicted object behaviour and prediction confidence from Step 2.

For each object, classify the interaction as:

- no conflict
- conditional
- conflict

Definitions:

no conflict
= the candidate's expected motion does not interfere with the predicted object behaviour within the planning horizon

conditional
= conflict depends on uncertain object behaviour or uncertain temporal/spatial overlap

conflict
= the candidate would move the ego into an unsafe interaction with the predicted object behaviour

Briefly explain each classification.

Step B — Candidate safety

Based on all object interactions, classify the candidate as:

- viable
- conditional
- unsafe

Use:

viable
= no relevant object creates a conflict

conditional
= no confirmed conflict, but at least one relevant interaction remains uncertain

unsafe
= at least one relevant object creates a confirmed conflict

Eliminate unsafe candidates.

Step C — Future value lambda

For every candidate that remains viable or conditional, assign one future-value label:

- keeps options open
- forecloses options
- creates new conflict

Definitions:

keeps options open
= the ego retains the ability to adjust speed or direction further if the environment changes

forecloses options
= the candidate commits the ego to a state or path that is difficult to reverse within the next 1–2 seconds

creates new conflict
= the candidate introduces a new interaction risk that is not required by the current predicted environment

Reference the specific predicted object behaviour that supports the lambda assessment.

Q12 — HAMILTONIAN SELECTION
============================================================

Q12. What is the single optimal speed-direction pair?

Choose ONE candidate by weighing:

- immediate cost L from Q10

- candidate safety from Q11

Selection rules:

3. Prefer:
   keeps options open
   over
   forecloses options
   over
   creates new conflict.

4. Among candidates with equivalent safety and future value, choose the one with the lowest L.

5. Stay as close as possible to the historical ego behaviour whenever this remains safe and does not worsen future value.

- why it wins on L,
